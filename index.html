HOW I SHIP · COMPANY OF ONE

Vibe coding is a prompt. This is a company of one.

One operator, an AI collaborator with memory, and a boring, durable stack wired together. That's how the work above goes from an idea in the morning to a live link by dinner.

  1. 01
    The operator

    Me, as product manager, program manager, prompter and prototyper. I own the brief and the ship decision.

  2. 02
    Perplexity Computer

    The collaborator: research, planning, design, code and testing. It browses, builds and checks its own work.

  3. 03
    Projects & memory

    A workspace per initiative with instructions, files and a knowledge wiki. This is where the context-driven playbook lives.

  4. 04
    GitHub

    Every change saved and reversible. The source of record every other tool talks to.

  5. 05
    Vercel or Cloudflare

    Hosting, preview links on every change, custom domains, rollbacks in a click.

  6. 06
    Supabase

    A real database with auth, for when an app needs to remember orders, bookings or punches.

  7. 07
    Connected tools

    Mail, calendar, Drive, Slack and more, reachable from the same session writing the code.

  8. 08
    The browser

    Everything ships as a URL. No app store, no installer. Send a link, it loads on a phone.
